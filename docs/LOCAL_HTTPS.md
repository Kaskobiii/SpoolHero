# Private HTTPS for Android NFC

No domain purchase or router port forwarding is required. These commands run in the LXC console, in the folder containing this fork's docker-compose.yml.

For a fresh LXC with Docker Compose and Git installed:

```sh
git clone https://github.com/Kaskobiii/SpoolHero.git
cd SpoolHero
bash scripts/install.sh
bash scripts/enable-local-https.sh 192.168.0.100
```

For an existing checkout first run `git pull --ff-only`. Do not replace an existing database password or delete its volume. Enable the update service once with `bash scripts/enable-updater.sh` if upgrading an older install.

The HTTPS script starts Caddy beside the app. Ports 443 and 8081 must be free and allowed on the LXC's LAN firewall. Open **https://192.168.0.100** after installing the certificate below. The old HTTP address on port 5000 remains available for the printer connection. Caddy preserves the browser's Host header, including for API writes.

## One-time phone setup

On each Android phone:

1. Download **http://192.168.0.100:8081/spoolhero-root.crt** while on your trusted local network.
2. In Android Settings search for **Install a certificate**, choose **CA certificate**, and select that downloaded file. Android's wording varies by phone. This trusts your own Caddy certificate authority; only install the certificate generated by your own LXC.
3. Close/reopen Chrome and open **https://192.168.0.100**. The page should load without a certificate warning. Enable NFC in Android and allow NFC when SpoolHero asks.

Firefox and iPhone browsers do not support Web NFC. Installing the certificate does not add NFC support to those browsers.

Only the public root certificate is served on port 8081. Private keys stay in the Caddy data volume. Keep the `caddy_data` volume across updates; otherwise phones need to trust the new certificate authority. Nothing here publishes the app on the internet.

If the LXC address changes, rerun the HTTPS script with the new IP. Reserve 192.168.0.100 in your router to keep the address stable. Restart Caddy after changing its configuration with `docker compose -f docker-compose.yml -f deploy/docker-compose.https.yml restart caddy`.

## Updates from the app

Fresh Docker installations include the private updater. Open **Settings → Updates → Check for updates → Update now**. Updates take a database backup, replace only the app container, and wait for the health check. Keep this page open while the app restarts, then use **Reload updated app**. Run updates between prints.

The updater has the Docker socket inside the LXC, as explicitly authorized. It has no published port and accepts only a shared private token from SpoolHero's server. It runs fixed check/update commands; it does not accept arbitrary command text. Anyone who can manage this login-free SpoolHero installation can initiate an update.

If no image is newer, the page says so. GitHub source changes only become downloadable after the **Publish fork Docker image** workflow succeeds. A version beginning `sha256:` means that older image lacks a revision label.

The temporary native localhost instance can display the Updates page, but Docker update controls are only enabled on Docker installations with the updater service configured.
